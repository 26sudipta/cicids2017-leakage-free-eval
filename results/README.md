# Results

Metric tables and figures for E1 to E4 and SHAP. File names follow `<experiment>_<condition>_<kind>_<model>.csv`:

- `*_results.csv`: one row per model, aggregate metrics
- `*_perclass_*.csv`: per-class precision, recall, F1 and support
- `*_confusion_*.csv`: confusion matrices
- `figures/`: plots

Large intermediates (`*.pkl`, `*.npz`, SHAP cache) are gitignored and regenerated by the scripts in `src/`.
